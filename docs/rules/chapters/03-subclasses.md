# Подклассы

> Источник: PHB 2014. Пересказ механики, не дословная копия.

## Механика
### Подклассы (архетипы)

- Подкласс выбирается на уровне, указанном в классе (чаще всего 2–3).
- Даёт дополнительные умения на фиксированных уровнях.
- Детали — в карточке класса (`### Подклассы`). Статус реализации в MUD — [`docs/DND_RULES.md`](../../DND_RULES.md).
