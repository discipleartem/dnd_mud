# Нетленные Останки

> Источник: PHB 2014. Пересказ механики, не дословная копия.

## Параметры

| Параметр | Значение |
|----------|----------|
| Уровень | 2 уровень (ритуал) |
| Школа | Некромантия (`necromancy`) |
| Время | 1 действие |
| Дистанция | Касание |
| Компоненты | В, С, М (щепотка соли и по одной медной монетке на каждый глаз трупа, которые должны оставаться там всё время, пока активно заклинание) |
| Длительность | Пока не рассеется |

## Эффект

- Касание трупа/останков: пока активно, цель не разлагается и не может стать нежитью.
- Дни под заклинанием не считаются в лимите времени для воскрешения.
