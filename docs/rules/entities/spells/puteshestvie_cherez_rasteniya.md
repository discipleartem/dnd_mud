# Путешествие Через Растения

> Источник: PHB 2014. Пересказ механики, не дословная копия.

## Параметры




| Параметр | Значение |
|----------|----------|
| Уровень | 6 уровень |
| Школа | Вызов (`вызов`) |
| Время | 1 действие |
| Дистанция | 10 футов |
| Компоненты | В, С |
| Длительность | 1 раунд |

## Эффект
- Это заклинание создаёт магическую связь между неоживлённым растением с размером не меньше Большого, находящимся в пределах дистанции, и другим растением, находящимся на любом расстоянии на том же плане существования.
- Пока заклинание активно, все существа могут входить в целевое растение и выходить из растения, служащего местом назначения, использовав всего 5 футов перемещения.
