# Остановка Времени

> Источник: PHB 2014. Пересказ механики, не дословная копия.

## Параметры




| Параметр | Значение |
|----------|----------|
| Уровень | 9 уровень |
| Школа | Преобразование (`transmutation`) |
| Время | 1 действие |
| Дистанция | На себя |
| Компоненты | В |
| Длительность | Мгновенная |

## Эффект
- Для всех остальных существ время перестаёт течь, а вы получаете 1к4 + 1 ход подряд, во время которых можете совершать действия и перемещаться как обычно.
