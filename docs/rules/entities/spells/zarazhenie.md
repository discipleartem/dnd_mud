# Заражение

> Источник: PHB 2014. Пересказ механики, не дословная копия.

## Параметры

| Параметр | Значение |
|----------|----------|
| Уровень | 5 уровень |
| Школа | Некромантия (`necromancy`) |
| Время | 1 действие |
| Дистанция | Касание |
| Компоненты | В, С |
| Длительность | 7 days |

## Эффект

- Рукопашная атака заклинанием: при попадании цель заражена одной болезнью на ваш выбор; спасброски Телосложения в конце своих ходов.
- 3 успеха до 3 провалов — болезнь не действует; 3 провала — болезнь проявляется до снятия высшим восстановлением / подобным.
- Варианты (после 3 провалов): слепота; безумие (помеха/случайное поведение); гниль плоти (уязвимость к урону); трясучка (помеха атакам, Сл+Тел, скорость/2); и т.п. по PHB.
