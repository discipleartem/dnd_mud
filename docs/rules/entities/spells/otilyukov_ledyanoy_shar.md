# Отилюков Ледяной Шар

> Источник: PHB 2014. Пересказ механики, не дословная копия.

## Параметры




| Параметр | Значение |
|----------|----------|
| Уровень | 6 уровень |
| Школа | Воплощение (`evocation`) |
| Время | 1 действие |
| Дистанция | 300 футов |
| Компоненты | В, С, М (маленький хрустальный шар) |
| Длительность | Мгновенная |

## Эффект
- Все существа в этой области должны совершить спасбросок Телосложения.
- При провале существо получает урон холодом 10к6.
- При успехе оно получает половину урона.

## На больших уровнях

- Если вы накладываете это заклинание, используя ячейку 7 уровня или выше, урон увеличиваетс я на 1к6 за каждый уровень ячейки выше шестого.
