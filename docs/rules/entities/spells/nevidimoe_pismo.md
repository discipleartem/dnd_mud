# Невидимое Письмо

> Источник: PHB 2014. Пересказ механики, не дословная копия.

## Параметры

| Параметр | Значение |
|----------|----------|
| Уровень | 1 уровень (ритуал) |
| Школа | Иллюзия (`illusion`) |
| Время | 1 минута |
| Дистанция | Касание |
| Компоненты | С, М (свинцовые чернила, стоящие как минимум 10 зм, расходуемые заклинанием) |
| Длительность | Пока не рассеется |

## Эффект

- Письмо на пергаменте/бумаге становится нечитаемым для других (кажется иным текстом/непонятным), кроме вас и существ, указанных при накладывании.
- Существо с истинным зрением читает настоящее послание.
- Заклинание оканчивается при рассеивании или через 10 дней (если не продлено).
