# Прыжок

> Источник: PHB 2014. Пересказ механики, не дословная копия.

## Параметры

| Параметр | Значение |
|----------|----------|
| Уровень | 1 уровень |
| Школа | Преобразование (`transmutation`) |
| Время | 1 действие |
| Дистанция | Касание |
| Компоненты | В, С, М (задняя лапка кузнечика) |
| Длительность | 1 минута |

## Эффект

- Вы касаетесь существа.
- Пока заклинание активно, расстояние прыжка этого существа увеличивается в три раза.
