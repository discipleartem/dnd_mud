# Длань Бигби

> Источник: PHB 2014. Пересказ механики, не дословная копия.

| Параметр | Значение |

| Школа | Воплощение (`evocation`) |
| Время | 1 действие |
| Дистанция | 120 футов |

| Длительность | Концентрация, вплоть до 1 минуты |

## Эффект
- Когда хиты руки опускаются до 0, заклинание оканчивается.
- Если цель Среднего размера или меньше, вы совершаете проверку с преимуществом.
- Рука перемещается так, что находится между вами и целью, предоставляя вам от цели укрытие на половину.
- Цель не может пройти сквозь пространство руки, если её значение Силы не больше значения Силы руки.
