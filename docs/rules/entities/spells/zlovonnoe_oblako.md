# Зловонное Облако

> Источник: PHB 2014. Пересказ механики, не дословная копия.

## Параметры




| Параметр | Значение |
|----------|----------|
| Уровень | 3 уровень |
| Школа | Вызов (`вызов`) |
| Время | 1 действие |
| Дистанция | 90 футов |
| Компоненты | В, С, М (тухлое яйцо или несколько гнилых листьев капусты) |
| Длительность | Концентрация, вплоть до 1 минуты |

## Эффект
- Вы создаёте сферу с радиусом 20 футов жёлтого тошнотворного газа с центром на точке в пределах дистанции.
- Все существа, находящиеся полностью в облаке в начале своего хода, должны совершить спасбросок Телосложения от яда.
- Существа, которые не обязаны дышать, а также обладающие иммунитетом 228
