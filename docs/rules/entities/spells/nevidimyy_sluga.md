# Невидимый Слуга

> Источник: PHB 2014. Пересказ механики, не дословная копия.

## Параметры




| Параметр | Значение |
|----------|----------|
| Уровень | 1 уровень |
| Школа | Вызов (ритуал) (`вызов (ритуал)`) |
| Время | 1 действие |
| Дистанция | 60 футов |
| Компоненты | В, С, М (часть тетивы и кусочек дерева) |
| Длительность | 1 час |

## Эффект
- Это заклинание создаёт невидимую, бессознательную и бесформенную силу, выполняющую отдаваемые вами простые поручения.
- У него КД 10, 1 хит, Сила 2, и он не может атаковать.
- Если его хиты опускаются до 0, заклинание оканчивается.
