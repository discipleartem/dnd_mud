# Цунами

> Источник: PHB 2014. Пересказ механики, не дословная копия.

## Параметры




| Параметр | Значение |
|----------|----------|
| Уровень | 8 уровень |
| Школа | Вызов (`вызов`) |
| Время | 1 минута |
| Дистанция | Видимость |
| Компоненты | В, С |
| Длительность | Концентрация, вплоть до 6 раундов |

## Эффект
- Когда стена появляется, все существа в её области должны совершить спасбросок Силы.
- При провале они получают дробящий урон 6к10 или половину этого урона при успехе.
