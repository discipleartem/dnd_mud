# Завеса Стрел

> Источник: PHB 2014. Пересказ механики, не дословная копия.

## Параметры




| Параметр | Значение |
|----------|----------|
| Уровень | 2 уровень |
| Школа | Преобразование (`transmutation`) |
| Время | 1 действие |
| Дистанция | 5 футов |
| Компоненты | В, С, М (как минимум четыре стрелы или арбалетных болта) |
| Длительность | 8 часов |

## Эффект
- Существо должно преуспеть в спасброске Ловкости, иначе оно получит колющий урон 1к6.

## На больших уровнях

- Если вы накладываете это заклинание, используя ячейку 3 уровня или выше, количество боеприпасов увеличивается на два за каждый уровень ячейки выше второго.
