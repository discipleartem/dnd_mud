# Луч Болезни

> Источник: PHB 2014. Пересказ механики, не дословная копия.

## Параметры




| Параметр | Значение |
|----------|----------|
| Уровень | 1 уровень |
| Школа | Некромантия (`necromancy`) |
| Время | 1 действие |
| Дистанция | 60 футов |
| Компоненты | В, С |
| Длительность | Мгновенная |

## Эффект
- Совершите дальнобойную атаку заклинанием по цели.
- При попадании цель получает урон ядом 2к8 и должна совершить спасбросок Телосложения.

## На больших уровнях

- Если вы накладываете это заклинание, используя ячейку 2 уровня или выше, урон увеличивается на 1к8 за каждый уровень ячейки выше первого.
