# Разговор С Животными

> Источник: PHB 2014. Пересказ механики, не дословная копия.

## Параметры




| Параметр | Значение |
|----------|----------|
| Уровень | 1 уровень |
| Школа | Прорицание (ритуал) (`прорицание (ритуал)`) |
| Время | 1 действие |
| Дистанция | На себя |
| Компоненты | В, С |
| Длительность | 10 минут |

## Эффект
- Вы получаете на время действия заклинания возможность понимать зверей и общаться с ними устно.
- На усмотрение Мастера, вы можете попытаться убедить зверя оказать вам небольшую помощь.
