# Предвидение

> Источник: PHB 2014. Пересказ механики, не дословная копия.

## Параметры

| Параметр | Значение |
|----------|----------|
| Уровень | 9 уровень |
| Школа | Прорицание (`divination`) |
| Время | 1 минута |
| Дистанция | Касание |
| Компоненты | В, С, М (перо колибри) |
| Длительность | 8 часов |

## Эффект

- Вы касаетесь согласного существа, даруя ограниченную способность предвидеть будущее.
- Пока заклинание активно, цель нельзя застать врасплох, и она совершает с преимуществом броски атаки, проверки характеристик и спасброски.
- Кроме того, пока заклинание активно, другие существа совершают по цели броски атаки с помехой.
- Это заклинание мгновенно оканчивается, если вы активируете его ещё раз до окончания длительности.
