# Дромиджево Появление

> Источник: PHB 2014. Пересказ механики, не дословная копия.

## Параметры

| Параметр | Значение |
|----------|----------|
| Уровень | 6 уровень (ритуал) |
| Школа | Вызов (`conjuration`) |
| Время | 1 минута |
| Дистанция | Касание |
| Компоненты | В, С, М (сапфир стоимостью 1 000 зм) |
| Длительность | Пока не рассеется |

## Эффект

- Касание предмета ≤10 фунтов и ≤6 футов по длинной стороне; на предмете невидимая метка, на сапфире (М, 1000 зм) — невидимое имя предмета.
- Позже действием произнести имя и раздавить сапфир: предмет мгновенно появляется в руке (любая дистанция/план), заклинание оканчивается.
- Если существо держит предмет и преуспевает в спасброске Харизмы против Сл ваших заклинаний — призыв не срабатывает; вы узнаёте об этом, и заклинание не тратится (сапфир не уничтожается).
