# Защита От Яда

> Источник: PHB 2014. Пересказ механики, не дословная копия.

## Параметры

| Параметр | Значение |
|----------|----------|
| Уровень | 2 уровень |
| Школа | Ограждение (`abjuration`) |
| Время | 1 действие |
| Дистанция | Касание |
| Компоненты | В, С |
| Длительность | 1 час |

## Эффект

- Вы касаетесь существа.
- Если оно отравлено, вы нейтрализуете яд.
- Если на цель действуют несколько ядов, вы нейтрализуете тот, о котором знаете, либо же один случайным образом выбранный яд.
- Пока заклинание активно, цель совершает с преимуществом спасброски от отравленного состояния и получает сопротивление к урону ядом.
