# Радужные Брызги

> Источник: PHB 2014. Пересказ механики, не дословная копия.

## Параметры




| Параметр | Значение |
|----------|----------|
| Уровень | 7 уровень |
| Школа | Воплощение (`evocation`) |
| Время | 1 действие |
| Дистанция | На себя (60-футовый конус) |
| Компоненты | В, С |
| Длительность | Мгновенная |

## Эффект
- Все существа в пределах 60-футового конуса должны совершить спасбросок Ловкости.
- Цель получает урон огнём 10к6 при провале или половину этого урона при успехе.
- Цель получает урон кислотой 10к6 при провале или половину этого урона при успехе.
- Цель получает урон электричеством 10к6 при провале или половину этого урона при успехе.
- Цель получает урон ядом 10к6 при провале или половину этого урона при успехе.
- Цель получает урон холодом 10к6 при провале или половину этого урона при успехе.
- При провале цель становится опутанной.
- После этого цель в конце каждого своего хода совершает спасбросок Телосложения.
- В начале вашего следующего хода она совершает спасбросок Мудрости.
