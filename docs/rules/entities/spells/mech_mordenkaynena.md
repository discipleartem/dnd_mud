# Меч Морденкайнена

> Источник: PHB 2014. Пересказ механики, не дословная копия.

## Параметры




| Параметр | Значение |
|----------|----------|
| Уровень | 7 уровень |
| Школа | Воплощение (`evocation`) |
| Время | 1 действие |
| Дистанция | 60 футов |
| Компоненты | В, С, М (миниатюрный платиновый меч с рукояткой и навершием из меди и цинка, стоящий 250 зм) |
| Длительность | Концентрация, вплоть до 1 минуты |

## Эффект
- Когда меч появляется, вы совершаете рукопашную атаку заклинанием по цели на ваш выбор, находящейся в пределах 5 футов от меча.
- При попадании цель получает урон силовым полем 3к10.
