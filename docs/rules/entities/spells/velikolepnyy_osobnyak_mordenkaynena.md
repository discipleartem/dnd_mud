# Великолепный Особняк Морденкайнена

> Источник: PHB 2014. Пересказ механики, не дословная копия.

## Параметры




| Параметр | Значение |
|----------|----------|
| Уровень | 7 уровень |
| Школа | Вызов (`вызов`) |
| Время | 1 минута |
| Дистанция | 300 футов |
| Компоненты | В, С, М (миниатюрная дверь из слоновой кости, кусочек полированного мрамора и крошечная серебряная ложка; каждый предмет должен стоить как минимум 5 зм) |
| Длительность | 24 часа |

## Эффект
- Дверь невидима, когда закрыта.
- Вы можете создать любую планировку, но пространство не может превышать 50 кубов с длиной ребра в 10 футов.
