# Ускорение

> Источник: PHB 2014. Пересказ механики, не дословная копия.

## Параметры

| Параметр | Значение |
|----------|----------|
| Уровень | 3 уровень |
| Школа | Преобразование (`transmutation`) |
| Время | 1 действие |
| Дистанция | 30 футов |
| Компоненты | В, С, М (стружка корня лакрицы) |
| Длительность | Концентрация, вплоть до 1 минуты |

## Эффект

- Выберите согласное существо, видимое в пределах дистанции.
- Пока заклинание активно, скорость
