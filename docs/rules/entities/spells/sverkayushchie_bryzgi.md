# Сверкающие Брызги

> Источник: PHB 2014. Пересказ механики, не дословная копия.

## Параметры

| Параметр | Значение |
|----------|----------|
| Уровень | 1 уровень |
| Школа | Иллюзия (`illusion`) |
| Время | 1 действие |
| Дистанция | На себя (15-футовый конус) |
| Компоненты | В, С, М (щепотка порошка или песка, окрашенного в красный, жёлтый и синий цвет) |
| Длительность | 1 раунд |

## Эффект

- Конус 15 футов: бросок 6к10; ослепить существ в порядке возрастания текущих хитов (пропуск бессознательных/невидящих), пока сумма хитов ≤ результата.
- Ослепление до конца вашего следующего хода.

## На больших уровнях

- +2к10 за каждый уровень ячейки выше 1.
