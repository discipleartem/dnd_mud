# Палящий Луч

> Источник: PHB 2014. Пересказ механики, не дословная копия.

## Параметры




| Параметр | Значение |
|----------|----------|
| Уровень | 2 уровень |
| Школа | Воплощение (`evocation`) |
| Время | 1 действие |
| Дистанция | 120 футов |
| Компоненты | В, С |
| Длительность | Мгновенная |

## Эффект
- Для каждого луча совершите дальнобойную атаку заклинанием.
- При попадании цель получает урон огнём 2к6.

## На больших уровнях

- Если вы накладываете это заклинание, используя ячейку 3 уровня или выше, вы создаёте один дополнительный луч за каждый уровень ячейки выше второго.
