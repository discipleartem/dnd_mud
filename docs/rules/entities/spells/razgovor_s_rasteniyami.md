# Разговор С Растениями

> Источник: PHB 2014. Пересказ механики, не дословная копия.

## Параметры




| Параметр | Значение |
|----------|----------|
| Уровень | 3 уровень |
| Школа | Преобразование (`transmutation`) |
| Время | 1 действие |
| Дистанция | На себя (30-футовый радиус) |
| Компоненты | В, С |
| Длительность | 10 минут |

## Эффект
- Вы можете также превратить на время действия заклинания труднопроходимую местность, вызванную растениями (кусты и заросли), в обычную местность.
- Вы можете превратить на время действия заклинания обычную местность в труднопроходимую, если там есть растения, например, заставляя ветки и лианы хватать преследователей.
