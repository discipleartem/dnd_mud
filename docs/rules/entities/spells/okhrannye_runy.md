# Охранные Руны

> Источник: PHB 2014. Пересказ механики, не дословная копия.

## Параметры

| Параметр | Значение |
|----------|----------|
| Уровень | 3 уровень |
| Школа | Ограждение (`abjuration`) |
| Время | 1 час |
| Дистанция | Касание |
| Компоненты | В, С, М (благовония и растолчённый бриллиант, стоящий как минимум 200 зм, расходуемый заклинанием) |
| Длительность | Пока не будут рассеяны или пока не сработают |

## Эффект

- Начертать глиф на поверхности (≤10 футов диаметр) или в закрывающемся предмете; при нарушении условий — срабатывает.
- Сл обнаружения/обезвреживания = Сл ваших заклинаний (Расследование / Воровские инструменты).
- Взрывная руна: сфера 20 футов, спасбросок Ловкости, 5к8 урона кислотой/холодом/огнём/молнией/громом (выбор) или половина.
- Заклинательная руна: хранит совместимое заклинание ≤ уровня ячейки охранных рун; при срабатывании наложится с вашими параметрами.

## На больших уровнях

- Урон взрывной руны +1к8 за каждый уровень ячейки выше 3.
