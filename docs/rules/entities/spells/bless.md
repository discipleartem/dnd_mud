# Благословение

> Источник: PHB 2014. Пересказ механики, не дословная копия.

## Параметры




| Параметр | Значение |
|----------|----------|
| Уровень | 1 уровень |
| Школа | Очарование (`enchantment`) |
| Время | 1 действие |
| Дистанция | 30 футов |
| Компоненты | В, С, М (капля святой воды) |
| Длительность | Концентрация, вплоть до 1 минуты |

## Эффект
- Каждый раз, когда до окончания заклинания цель совершает бросок атаки или спасбросок, она может бросить к4 и добавить выпавшее число к результату.
