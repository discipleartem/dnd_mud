# Полёт

> Источник: PHB 2014. Пересказ механики, не дословная копия.

## Параметры




| Параметр | Значение |
|----------|----------|
| Уровень | 3 уровень |
| Школа | Преобразование (`transmutation`) |
| Время | 1 действие |
| Дистанция | Касание |
| Компоненты | В, С, М (перо из крыла любой птицы) |
| Длительность | Концентрация, вплоть до 10 минут |

## Эффект
- Когда заклинание оканчивается, цель падает, если всё ещё находится в полёте и ничем не может остановить падение.

## На больших уровнях

- Если вы накладываете это заклинание, используя ячейку 4 уровня или выше, вы можете сделать целью одно дополнительное существо за каждый уровень ячейки выше 3.
