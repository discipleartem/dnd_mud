# Разговор С Мёртвыми

> Источник: PHB 2014. Пересказ механики, не дословная копия.

## Параметры




| Параметр | Значение |
|----------|----------|
| Уровень | 3 уровень |
| Школа | Некромантия (`necromancy`) |
| Время | 1 действие |
| Дистанция | 10 футов |
| Компоненты | В, С, М (горящие благовония) |
| Длительность | 10 минут |

## Эффект
- У трупа должен быть рот, и он не может быть нежитью.
- Таким образом, труп не может узнавать новую информацию, не осознаёт того, что происходило после его смерти, и не может размышлять о будущих событиях.
