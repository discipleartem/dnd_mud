# Предосторожность

> Источник: PHB 2014. Пересказ механики, не дословная копия.

## Параметры

| Параметр | Значение |
|----------|----------|
| Уровень | 6 уровень |
| Школа | Воплощение (`evocation`) |
| Время | 10 минут |
| Дистанция | На себя |
| Компоненты | В, С, М (ваша статуэтка, вырезанная из слоновой кости, украшенная драгоценными камнями и стоящая как минимум 1 500 зм) |
| Длительность | 10 days |

## Эффект

- На себя: связать одно заклинание ≤5 уровня с временем накладывания 1 действие, нацеливаемое только на вас, потратив ячейку на оба.
- Задать обстоятельство; когда оно наступает, связанное заклинание срабатывает автоматически (ваша концентрация не нужна для срабатывания).
- Одновременно активна только одна предосторожность; материал — статуэтка вас ≥1500 зм.
