# Быстрый Колчан

> Источник: PHB 2014. Пересказ механики, не дословная копия.

## Параметры




| Параметр | Значение |
|----------|----------|
| Уровень | 5 уровень |
| Школа | Преобразование (`transmutation`) |
| Время | 1 бонусное действие |
| Дистанция | Касание |
| Компоненты | В, С, М (колчан, содержащий как минимум один боеприпас) |
| Длительность | Концентрация, вплоть до 1 минуты |

## Эффект
- Пока заклинание активно, вы в каждом своём ходу можете бонусным действием совершить две атаки оружием, использующим боеприпасы из колчана.
- Каждый раз, когда вы совершаете такую дальнобойную атаку, ваш колчан при помощи магии заменяет использованный вами боеприпас таким же немагическим боеприпасом.
