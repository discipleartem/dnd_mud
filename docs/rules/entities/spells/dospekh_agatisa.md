# Доспех Агатиса

> Источник: PHB 2014. Пересказ механики, не дословная копия.

## Параметры




| Параметр | Значение |
|----------|----------|
| Уровень | 1 уровень |
| Школа | Ограждение (`abjuration`) |
| Время | 1 действие |
| Дистанция | На себя |
| Компоненты | В, С, М (чашка воды) |
| Длительность | 1 час |

## Эффект
- Если существо попадает по вам рукопашной атакой, пока у вас есть эти хиты, оно получает урон холодом 5.

## На больших уровнях

- Если вы накладываете это заклинание, используя ячейку 2 уровня или выше, и временные хиты и урон холодом увеличиваются на 5 за каждый уровень ячейки выше первого.
