# Луч Слабости

> Источник: PHB 2014. Пересказ механики, не дословная копия.

## Параметры




| Параметр | Значение |
|----------|----------|
| Уровень | 2 уровень |
| Школа | Некромантия (`necromancy`) |
| Время | 1 действие |
| Дистанция | 60 футов |
| Компоненты | В, С |
| Длительность | Концентрация, вплоть до 1 минуты |

## Эффект
- Совершите по цели дальнобойную атаку заклинанием.
- При попадании цель до конца действия заклинания причиняет только половину урона атаками оружием, использующими Силу.
- В конце каждого своего хода цель может совершать спасбросок Телосложения от этого заклинания.
- Компоненты: В, С Длительность: Концентрация, вплоть до 10 минут Вы создаёте связанные порталы для телепортации, остающиеся открытыми на время длительности.
- Если портал должен открыться в пространстве, занятом существом, заклинание проваливается.
