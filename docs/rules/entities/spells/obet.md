# Обет

> Источник: PHB 2014. Пересказ механики, не дословная копия.

## Параметры

| Параметр | Значение |
|----------|----------|
| Уровень | 5 уровень |
| Школа | Очарование (`enchantment`) |
| Время | 1 минута |
| Дистанция | 60 футов |
| Компоненты | В |
| Длительность | 30 days |

## Эффект

- Существо в пределах дистанции, слышащее вас: спасбросок Мудрости; при провале очаровано на время действия, пока выполняет служебный приказ (без явного самоубийства).
- Каждый раз, когда действует вопреки приказу — 5к10 психическим уроном (не чаще 1/день).
- Можно окончить действием; также снимается снятие проклятия, высшее восстановление или исполнение желаний.

## На больших уровнях

- Ячейка 7–8: длительность до 1 года; ячейка 9: пока не рассеется.
