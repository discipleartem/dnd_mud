# Волшебная Стрела

> Источник: PHB 2014. Пересказ механики, не дословная копия.

## Параметры




| Параметр | Значение |
|----------|----------|
| Уровень | 1 уровень |
| Школа | Воплощение (`evocation`) |
| Время | 1 действие |
| Дистанция | 120 футов |
| Компоненты | В, С |
| Длительность | Мгновенная |

## Эффект
- Каждый дротик причиняет урон силовым полем 1к4 + 1.

## На больших уровнях

- Если вы накладываете это заклинание, используя ячейку 2 уровня или выше, заклинание создаёт по одному дополнительному дротику за каждый уровень ячейки выше первого.
