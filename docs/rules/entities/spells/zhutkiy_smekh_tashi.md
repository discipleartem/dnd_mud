# Жуткий Смех Таши

> Источник: PHB 2014. Пересказ механики, не дословная копия.

## Параметры




| Параметр | Значение |
|----------|----------|
| Уровень | 1 уровень |
| Школа | Очарование (`enchantment`) |
| Время | 1 действие |
| Дистанция | 30 футов |
| Компоненты | В, С, М (маленькие пирожные и перо, которым нужно махать в воздухе) |
| Длительность | Концентрация, вплоть до 1 минуты |

## Эффект
- Цель должна преуспеть в спасброске Мудрости, иначе она падает ничком, становится недееспособной, и в течение действия заклинания не может встать.
- В конце каждого своего хода, и каждый раз при получении урона цель может совершать новый спасбросок Мудрости.
- Спасбросок совершается с преимуществом, если он был вызван получением урона.
