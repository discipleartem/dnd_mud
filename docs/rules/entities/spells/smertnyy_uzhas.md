# Смертный Ужас

> Источник: PHB 2014. Пересказ механики, не дословная копия.

## Параметры




| Параметр | Значение |
|----------|----------|
| Уровень | 9 уровень |
| Школа | Иллюзия (`illusion`) |
| Время | 1 действие |
| Дистанция | 120 футов |
| Компоненты | В, С |
| Длительность | Концентрация, вплоть до 1 минуты |

## Эффект
- Все существа в сфере с радиусом 30 футов с центром на выбранной точке в пределах дистанции, должны совершить спасбросок Мудрости.
- В конце каждого своего хода испуганное существо должно преуспевать в спасброске Мудрости, иначе оно получает урон психической энергией 4к10.
