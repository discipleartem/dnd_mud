# Солнечный Ожог

> Источник: PHB 2014. Пересказ механики, не дословная копия.

## Параметры




| Параметр | Значение |
|----------|----------|
| Уровень | 8 уровень |
| Школа | Воплощение (`evocation`) |
| Время | 1 действие |
| Дистанция | 150 футов |
| Компоненты | В, С, М (огонь и кусочек солнечного камня) |
| Длительность | Мгновенная |

## Эффект
- Все существа, находящиеся в нём, должны совершить спасбросок Телосложения.
- При провале существо получает урон излучением 12к6 и становится ослеплённым на 1 минуту.
- При успехе оно получает половину урона и не становится ослеплённым.
- Нежить и слизи совершают этот спасбросок с помехой.
