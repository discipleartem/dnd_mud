# Разящее Око

> Источник: PHB 2014. Пересказ механики, не дословная копия.

## Параметры

| Параметр | Значение |
|----------|----------|
| Уровень | 6 уровень |
| Школа | Некромантия (`necromancy`) |
| Время | 1 действие |
| Дистанция | На себя |
| Компоненты | В, С |
| Длительность | Концентрация, вплоть до 1 минуты |

## Эффект

- В свой ход (включая ход накладывания) выбрать существо в пределах 60 футов в линии обзора: спасбросок Мудрости или один эффект на ваш выбор.
- Сон: бессознательно до конца заклинания / урона / тряски действием.
- Паника: испугано вами; каждый ход должно отдаляться, пока возможно; повторный спасбросок в конце хода.
- Болезнь: помеха на броски атаки и проверки характеристик до конца заклинания.
