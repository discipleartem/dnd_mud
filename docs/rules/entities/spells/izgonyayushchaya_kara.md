# Изгоняющая Кара

> Источник: PHB 2014. Пересказ механики, не дословная копия.

## Параметры

| Параметр | Значение |
|----------|----------|
| Уровень | 5 уровень |
| Школа | Ограждение (`abjuration`) |
| Время | 1 бонусное действие |
| Дистанция | На себя |
| Компоненты | В |
| Длительность | Концентрация, вплоть до 1 минуты |

## Эффект

- Следующее попадание оружием, пока заклинание активно: цель получает дополнительно 5к10 урона силовым полем.
- Если после этого урона у цели остаётся 50 хитов или меньше, её изгоняют.
- Исчадие, небожитель, фея или элементаль возвращается на родной план (при успехе — заклинание оканчивается для этой цели по правилам PHB); иное существо — на безопасный demiplane до конца заклинания, затем возвращается в пространство (или ближайшее свободное).
