# Рост Растений

> Источник: PHB 2014. Пересказ механики, не дословная копия.

## Параметры




| Параметр | Значение |
|----------|----------|
| Уровень | 3 уровень |
| Школа | Преобразование (`transmutation`) |
| Время | 1 действие или 8 часов |
| Дистанция | 150 футов |
| Компоненты | В, С |
| Длительность | Мгновенная |

## Эффект
- Все обычные растения в пределах 100-футового радиуса с центром на этой точке становятся густыми и рослыми.
- Все растения в радиусе полумили с центром на точке в пределах дистанции становятся удобренными на 1 год.
