# Маяк Надежды

> Источник: PHB 2014. Пересказ механики, не дословная копия.

## Параметры

| Параметр | Значение |
|----------|----------|
| Уровень | 3 уровень |
| Школа | Ограждение (`abjuration`) |
| Время | 1 действие |
| Дистанция | 30 футов |
| Компоненты | В, С |
| Длительность | Концентрация, вплоть до 1 минуты |

## Эффект

- Это заклинание дарует надежду и живучесть.
- Выберите любое количество существ в пределах дистанции.
- Пока заклинание активно, все цели совершают спасброски Мудрости и спасброски от смерти с преимуществом, а также восстанавливают от любого лечения максимально возможное количество хитов.
