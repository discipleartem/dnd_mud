# Воспламеняющаяся Туча

> Источник: PHB 2014. Пересказ механики, не дословная копия.

## Параметры




| Параметр | Значение |
|----------|----------|
| Уровень | 8 уровень |
| Школа | Вызов (`вызов`) |
| Время | 1 действие |
| Дистанция | 150 футов |
| Компоненты | В, С |
| Длительность | Концентрация, вплоть до 1 минуты |

## Эффект
- Кружащееся облако дыма с ярко-белыми огоньками появляется в сфере с радиусом 20 футов с центром на точке, находящейся в пределах дистанции.
- Когда облако появляется, все существа, находящиеся в нём, должны совершить спасбросок Ловкости.
- Существо получает урон огнём 10к8 при провале или половину урона при успехе.
- Существа должны также совершать этот спасбросок, когда впервые за ход входят в область заклинания или оканчивают там ход.
