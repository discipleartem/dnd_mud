# Паук

> Источник: PHB 2014. Пересказ механики, не дословная копия.

## Параметры




| Параметр | Значение |
|----------|----------|
| Уровень | 2 уровень |
| Школа | Преобразование (`transmutation`) |
| Время | 1 действие |
| Дистанция | Касание |
| Компоненты | В, С, М (капля битума и паук) |
| Длительность | Концентрация, вплоть до 1 часа |

## Эффект
- Пока заклинание активно, одно согласное существо, которого вы касаетесь, получает возможность перемещаться вверх, вниз и вдоль вертикальных поверхностей, а также по потолкам, оставляя руки свободными.
- Цель также получает скорость лазания, равную своей скорости ходьбы.
