# Каменная Стена

> Источник: PHB 2014. Пересказ механики, не дословная копия.

## Параметры




| Параметр | Значение |
|----------|----------|
| Уровень | 5 уровень |
| Школа | Воплощение (`evocation`) |
| Время | 1 действие |
| Дистанция | 120 футов |
| Компоненты | В, С, М (небольшой кусочек гранита) |
| Длительность | Концентрация, вплоть до 10 минут |

## Эффект
- Если существо со всех сторон окружается стеной (или стеной и другой сплошной поверхностью), это существо может совершить спасбросок Ловкости.
- Стена может иметь любую форму, хотя и не может занимать одно пространство с существами и предметами.
- Стена является предметом, изготовленным из камня, которому можно причинить урон и, тем самым, пробить.
- Если вы поддерживаете концентрацию на этом заклинании в течение всей длительности, стена становится постоянной, и с этого момента её уже нельзя будет рассеять.
