# Изменение Тяготения

> Источник: PHB 2014. Пересказ механики, не дословная копия.

## Параметры

| Параметр | Значение |
|----------|----------|
| Уровень | 7 уровень |
| Школа | Преобразование (`transmutation`) |
| Время | 1 действие |
| Дистанция | 100 футов |
| Компоненты | В, С, М (магнетит и железные опилки) |
| Длительность | Концентрация, вплоть до 1 минуты |

## Эффект

- Это заклинание обращает гравитацию в цилиндре с радиусом 50 футов и высотой 100 футов с центром на точке в пределах дистанции.
