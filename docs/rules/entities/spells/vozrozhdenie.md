# Возрождение

> Источник: PHB 2014. Пересказ механики, не дословная копия.

## Параметры

| Параметр | Значение |
|----------|----------|
| Уровень | 3 уровень |
| Школа | Некромантия (`necromancy`) |
| Время | 1 действие |
| Дистанция | Касание |
| Компоненты | В, С, М (бриллиант, стоящий 300 зм, расходуемый заклинанием) |
| Длительность | Мгновенная |

## Эффект

- Вы касаетесь существа, мёртвого не больше минуты.
- Это существо возвращается к жизни с 1 хитом.
- Это заклинание не может оживить существ, умерших от старости, а также не восстанавливает отсутствующие части тел.
