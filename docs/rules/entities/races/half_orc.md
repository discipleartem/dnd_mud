# Полуорк

> Источник: PHB 2014. Пересказ механики, не дословная копия.

## Механика
### Увеличение характеристик

- Сила +2, Телосложение +1.

### Размер

- Средний.

### Скорость

- 30 футов.

### Тёмное зрение

- 60 футов.

### Неукротимость

- При снижении до 0 хитов, но не убит — можно остаться с 1 хитом (1/долгий отдых).

### Свирепые атаки

- При критическом попадании рукопашной атакой — один дополнительный куб урона оружия.

### Языки

- Общий и орочий.
