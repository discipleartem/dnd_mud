# Радикальный рефакторинг dnd_mud для упрощения архитектуры

План радикального упрощения проекта: слияние гранулярных пакетов в единые модули, удаление фасадных прослоек, сокращение дублирующего кода и избыточных абстракций.

**Статус:** выполнен на ветке `refactor/simplify` (см. `docs/CHANGELOG.md` §Unreleased → Architecture simplify).

## Цели

- Сократить количество файлов с ~85 до ~50
- Уменьшить LOC за счёт удаления дублирующих фасадов
- Упростить архитектуру: уменьшить косвенность импортов
- Сохранить функциональность, обновить тесты
